# VinylAgent

**Application deployment and workflow automation**

Public project summary · Personal application in development

## Overview

VinylAgent brings albums, content ideas, planned posts, and performance information into one application. It supports a Hebrew content workflow, with structured storage and integration points in the backend.

This is a personal project developed with AI assistance, independently of my employer. I use it to build practical experience in Linux, application operations, and API-based automation.

## Work completed

- Deployed a Node.js and SQLite application on Ubuntu Server using Docker Compose.
- Connected the application to n8n through an authenticated API for a scheduled daily report.
- Validated application health, readiness, and database integrity during deployment.
- Preserved verified database backups and rollback copies during the move from Windows to Linux.
- Configured the application to run as a non-root container without publishing its service port to the host.

## Technologies

Node.js · Express · JavaScript · SQLite · Ubuntu Server · Docker Compose · n8n · API integrations

## Current status and scope

The application remains in development. Deployment and workflow integration are documented; individual external integrations have their own testing and release steps.

This page describes the project and its recorded work. It does not provide the application's source code or claim that every planned integration has been released.

## What I am learning

API boundaries, persistent data, service health, controlled changes, and the operational details of connecting an application to an automated workflow.
